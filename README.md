# Claude Companion — أيقونة جدولة داخل نافذة كلود كود

إضافة VS Code خفيفة بتضيف **أيقونة ⏰** لجدولة مهام كلود — **من غير ما تلمس شات كلود كود** (الشات يفضل بتاع كلود زي ما هو). مفيش لوحة منفصلة دائمة؛ بس أيقونة بتفتح لوحة جدولة صغيرة لما تحتاجها.

## إزاي توصل للأيقونة؟
فيه 3 طرق (كلها بتفتح نفس اللوحة):
1. **أيقونة الساعة ⏰ في شريط أدوات نافذة كلود كود** (أعلى التبويب لما تكون نافذة كلود مفتوحة كـ Tab).
2. **أيقونة "⏰ جدولة كلود" في شريط الحالة السفلي** (ظاهرة دايماً).
3. **Command Palette** → اكتب: `جدولة مهمة كلود`.

## اللوحة بتعمل إيه؟
- **نوع الجدولة:**
  - *عند تجديد الحصة (كل 5 ساعات)* — ينفّذ المهمة أول ما تتجدد نافذة الحصة (بيقرأ وقت التجديد الحقيقي من كلود).
  - *وقت وتاريخ محدد* — منتقي **تاريخ ووقت**، مع تكرار: مرة واحدة / كل ساعة / يومي / أسبوعي / كل N ساعة.
- **المهمة:** محرّر نص (بيتحفظ في `task.md`).
- **أزرار:** حفظ وتشغيل / إيقاف / فتح المهمة في محرر / فتح شات كلود / تحديث.
- **الحالة:** شغّال أو متوقف، التشغيل القادم، **عدّاد تنازلي**، والسجل.

اللوحة بتقرأ وتكتب في `config.json` بتاع المجدول وبتشغّل نفس سكربتات PowerShell.

## التشغيل (وضع تطوير — بدون build)
1. في VS Code: `File > Open Folder` → افتح مجلد `claude-companion`.
2. اضغط **F5** → تفتح نافذة Extension Development Host والإضافة شغّالة فيها.
3. افتح شات كلود كود، وهتلاقي أيقونة ⏰ فوق — أو استخدم أيقونة شريط الحالة.

## تثبيت دائم (اختياري)
```powershell
npm install -g @vscode/vsce
cd f:\AI\auto-code\claude-companion
vsce package
code --install-extension .\claude-companion-0.2.0.vsix
```

## ملاحظات
- الأيقونة اللي في شريط أدوات نافذة كلود بتظهر لما كلود مفتوح كـ **Tab** (وضع panel، وهو الافتراضي). لو بتستخدمه في الشريط الجانبي، استخدم أيقونة شريط الحالة أو الـ Command Palette.
- "حفظ وتشغيل" بيعيد تشغيل الـ watcher عشان الإعدادات الجديدة تسري فوراً.
- لا يمكن — تقنياً — إضافة أيقونة *جوّه* الـ webview بتاعت شات كلود نفسه؛ فالأيقونة بتظهر في شريط أدوات المحرِّر المحيط بالنافذة (أقرب مكان مسموح به في VS Code).
